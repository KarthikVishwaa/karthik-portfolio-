# Karthik Portfolio 🚀

A modern and fully responsive developer portfolio built using **Next.js**, **TypeScript**, and **Tailwind CSS**.

This portfolio showcases projects, skills, animations, and responsive UI/UX with smooth interactions and clean design.

---


# ✨ Features

- Modern responsive UI
- Smooth animations and transitions
- Project showcase section
- Skills & tech stack section
- Fully mobile responsive
- Optimized performance
- Clean folder structure
- TypeScript support
- Tailwind CSS styling
- Next.js App Router architecture
